# 🏥 Healthcare AI Chatbot

An AI-powered healthcare chatbot that provides healthcare-related information through an interactive web interface.

**Technologies:** Python, NLP, NLTK, spaCy, Streamlit.

**Features:** Interactive chat, healthcare responses, audio input, image upload, and camera support.
